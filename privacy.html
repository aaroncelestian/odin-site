Privacy

Last updated: August 2, 2026

Odin is built to keep your writing with you. Your manuscripts live in project bundles you control. We do not sell your content, and the app does not include third-party advertising or analytics SDKs.

What Odin is

Odin is a native writing app for Mac, iPad, and iPhone. Each project is an .odin package on disk: manuscript sections, figures, references, review threads, templates you import, and local history. You open, move, back up, and delete those packages like any other files.

Data we do not collect

As of this policy, the Odin app and this marketing site do not:

  • Run advertising networks or sell personal information
  • Embed third-party analytics or crash-reporting SDKs in the app
  • Upload your manuscript to an Odin-operated cloud by default
  • Require an Odin account to write

Information on your devices

Odin stores project and preference data locally, including:

  • Project bundles — in your chosen library folder (by default iCloud Drive / Odin when iCloud is available, otherwise on-device Documents / Odin), or another folder you select
  • App preferences — settings such as formatting-bar layout, recent projects, and notification options (via system storage such as UserDefaults)
  • Credentials you connect — if you sign in to GitHub, the OAuth token and account login are stored in the system Keychain on your device
  • Global reference library — a cross-project bibliography kept in Application Support on the device

You can remove projects by deleting their bundles, disconnect GitHub from within the app, and clear app data by removing the app (and any Keychain items associated with it, subject to system behavior).

Optional services you choose

Some features only run when you turn them on or take an explicit action. Those services receive only what is needed for that action.

Apple iCloud

If you use the default library location on iCloud Drive, your .odin packages sync through Apple’s iCloud under your Apple ID. Odin does not operate a separate cloud database for projects. Apple’s handling of iCloud data is governed by Apple’s Privacy Policy.

GitHub sync and collaboration

If you publish or sync a project with GitHub, Odin uses GitHub OAuth (via the system browser / authentication session) and communicates with GitHub’s APIs to create or update repositories you choose. Your manuscript and related bundle files go to your GitHub account (typically a private repository you control). GitHub’s processing is governed by GitHub’s Privacy Statement.

Shared review comments live in the project bundle (Review/threads.json) and travel with that GitHub repository when you sync. Optional web collaboration uses the separate Odin Web Editor at a site you open by invite link; that editor works against the same GitHub project rather than an Odin content vault.

Reference lookup (DOI)

When you import a citation by DOI, Odin requests metadata from Crossref (api.crossref.org) for that DOI. The request includes the DOI you entered; Crossref’s own policies apply to their service.

Notifications

On Mac, optional remote-update notifications can alert you when a published project has new remote changes. That feature uses your local GitHub credentials and preferences you set in the app; notification permission is requested through the system when you enable it.

Local asset helper

Figure previews may use a local asset sidecar on your machine (loopback HTTP). It is not an Odin-operated internet service for storing your writing.

This website

The Odin marketing site is a static page. It may use browser localStorage for small presentation details (for example, rotating a welcome tagline). If a waitlist or download form is added later, that form will state what is collected and where it is stored before you submit.

Hosting providers (for example Netlify or similar) may log standard technical data such as IP address and request metadata in order to serve the site. Those logs are controlled by the host’s policies.

Children

Odin is not directed at children under 13, and we do not knowingly collect personal information from children.

Changes

If this policy changes in a material way, we will update the “Last updated” date on this page. Continued use of Odin or this site after an update means you have had a chance to review the revised policy.

Contact

Questions about privacy in Odin can be sent through the Odin GitHub repository or the contact channel listed with the app when it is published on the App Store.
