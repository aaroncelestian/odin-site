Odin is a writing environment for researchers. Your manuscript, figures, references, and review threads live in a single project bundle — not scattered across Desktop, Downloads, and half a dozen apps.

Open a shared project See how it works

One bundle. Every artifact.

Write first

A distraction-free manuscript editor with real Markdown underneath. The writing column dominates; tools appear only when the work demands them.

References built in

Import by DOI or BibTeX, cite with [@key], and export with a formatted bibliography. No external reference manager required.

Figures without the mess

Figures live alongside the text in the project bundle and travel with it — publish-ready when you are.

Versioned by default

Every save is history. Sync to GitHub with plain-language actions: publish, save changes, get latest.

Review threads

Committee members and co-authors leave anchored comments right in the manuscript — no PDF ping-pong.

Export anywhere

Markdown, HTML, DOCX, and PDF from the same source. One manuscript, many outputs.

Collaborate through Odin Web

Authors write in native Odin on Mac and iPad. Collaborators need nothing but a browser and a free GitHub account: open the invite link, sign in, edit sections, and leave review comments. Changes flow back to the author through GitHub.

  1. Author publishes the project to GitHub from Odin.
  2. Author invites collaborators to the repository.
  3. Collaborators sign in to Odin Web with their own GitHub account.
  4. Everyone edits and reviews; Odin keeps the history.

The anvil came first

Hephaestus didn’t architect a workshop and then populate it. He landed, and he started working — the tools emerged from the act of making.

Odin is built the same way. You don’t build the project; you discover it. Each tool exists because the act of writing demanded it — not because a roadmap said so. If a feature doesn’t emerge from genuine friction felt while working, it doesn’t belong.
