The problem

Your project lives in too many places.

Manuscripts in one app. Figures in a folder. Citations in another tab. Drafts and notes scattered until you alone can hold the whole thing in your head.

Odin holds the project — so you can write.

The bundle

Everything travels together.

An .odin package is the project: manuscript sections, figures, references, review threads, and history — one file to open, share, or sync.

  • Manuscript Sections as plain Markdown
  • Figures Full-resolution originals + editor previews
  • References Citations that stay with the work
  • History Checkpoints when you need them

The surface

Writing stays at the center.

Binder on one side, tools when you need them — never a maze of apps. Panels, sheets, and modes come to the manuscript. The prose column stays quiet.

Native on Mac, iPad, and iPhone. One library via iCloud when you want it.

What ships with the craft

Built for the work, not a feature matrix.

  • Editor Shape the manuscript where you write.
  • References Cite without leaving the page.
  • Export Markdown, HTML, DOCX, PDF, LaTeX.
  • Sync & collab GitHub publish, iCloud library, shared review.
